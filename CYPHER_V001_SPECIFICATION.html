1. EXECUTIVE SUMMARY

Project Definition

Cypher v001 is an embodied AI assistant featuring neural text-to-speech, real-time vision capabilities, and physical presence through embedded hardware. This document defines the complete engineering specification for delivering a production-ready v001 release.

Core Objectives

  • Implement streaming neural TTS with 5+ minute continuous speech capability
  • Establish standardized pipeline architecture for all features
  • Maintain existing Felix recognition while adding contextual awareness
  • Deploy on Raspberry Pi with complete audio I/O
  • Achieve 100% test coverage for critical paths

Success Metrics

2. DEVELOPMENT PRINCIPLES

The Three Commandments

  1. Working Code is Sacred - Never modify working features during development of new features
  2. No Feature Without Test - Every feature must have passing tests before considered complete
  3. One Phase at a Time - Complete current phase before beginning next

Feature Freeze Protocol

When a feature reaches working state:

  1. Tag in version control: git tag WORKING_[FEATURE]_v1
  2. Document in WORKS.md file
  3. Freeze for minimum 14 days
  4. Add comment blocks: # FROZEN UNTIL: [DATE]

Daily Discipline Framework

Morning: Review current phase objectives
Coding: Work ONLY on current phase tasks
Testing: Run test suite before any commit
Evening: Document progress in daily log
